# Estrutura de Dados

Repositório contendo os códigos, exercícios e implementações práticas desenvolvidos durante a disciplina de Estrutura de Dados.

## Estrutura do Projeto

### `atividadeRevisaoJava/`
Revisão dos conceitos fundamentais de Programação Orientada a Objetos (POO) em Java, incluindo herança, encapsulamento e composição de classes (`Funcionario`, `Gerente`, `Equipe` e `Projeto`).

### `testandoArranjos/`
Implementações e testes envolvendo estruturas de dados lineares e manipulação de memória:

* **`Aula02/`**: Implementação de vetores estáticos e dinâmicos, generalização com `Object` e tipos genéricos (`Caixa`), algoritmos de busca (linear e binária), matrizes/vetores de listas e uma aplicação prática de gerenciamento de contatos (`atividadeC`).
* **`Aula03/`**: Implementação e aplicação de Pilhas (`Stack`/`Pilha`) e Filas (`Fila`). Inclui exercícios práticos como conversão de decimal para binário (`decToBin`), resolução de labirintos (`Labirinto`) e simulação de fila de pacotes.

## Tecnologias

* **Linguagem:** Java
