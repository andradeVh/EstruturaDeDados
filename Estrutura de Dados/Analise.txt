Como era de se imaginar, na maioria dos casos a busca binária se sobressai em relação à busca sequencial, o melhor caso possível para a busca linear que podemos ver é o quando o valor procurado está no indice 0 (ou o ultimo indice caso esteja fazendo de trás pra frente) logo na primeira iteração, enquanto para a busca binária é o exato meio do arranjo. Se o valor alvo estiver do meio pro fim ou meio pro inicio, o tempo que leva pra busca binária é o mesmo, enquanto que, a busca linear é complemente sequencial e vai percorrer até o ultimo elemento se necessário, podendo fazer 100.000 comparações.
